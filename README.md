# 2023 산업연관분석 웹앱

한국은행 **2023년 산업연관표(연장표)** 의 투입산출표(생산자가격)를 브라우저에서 읽어 산업연관분석을 수행하는 웹앱입니다.
서버 없이 **GitHub Pages**로 게시하며, 계산은 방문자 브라우저의 **Pyodide(WebAssembly Python)** 가 합니다.

- GitHub: 코드와 Excel 파일 보관
- GitHub Pages: 웹사이트 파일 제공
- 방문자의 브라우저: Pyodide로 Python 실행 → Excel 읽기, 검증, 산업연관분석 (Excel은 추가 패키지 없이 Python 표준 라이브러리 zipfile·xml로 직접 읽고, 계산에는 numpy만 사용)

게시 주소: `https://사용자이름.github.io/저장소이름`

## 파일 구조

```
저장소 최상위/
|-- index.html      화면과 입력·결과 영역 구성
|-- style.css       화면 디자인
|-- app.js          버튼 동작과 결과 표시
|-- worker.js       별도 작업 공간에서 Python(Pyodide) 실행
|-- model.py        Excel 읽기, 검증, 경제 계산
|-- .nojekyll       Jekyll 처리 없이 정적 파일을 게시하도록 설정
|-- README.md       프로젝트 설명과 사용 방법
`-- data/
    |-- io-2023-large.xlsx    투입산출표 통합대분류(33부문)
    |-- io-2023-mid.xlsx      투입산출표 통합중분류(83부문)
    |-- io-2023-small.xlsx    투입산출표 통합소분류(165부문)
    |-- io-2023-basic.xlsx    투입산출표 기본부문(380부문)
    `-- product-class.xlsx    2020 기준년 상품분류(기본부문-소-중-대분류 연결표)
```

## 웹앱 사용법

1. 첫 화면에서 **Python 엔진 준비 완료** 표시가 뜰 때까지 기다립니다(처음에는 Pyodide를 내려받느라 수십 초 걸립니다).
2. **분류(대분류·중분류·소분류·기본부문)** 를 고르고 **투입산출표 불러오기** 버튼을 누릅니다. Excel 자료가 로딩되고 분석 탭이 열립니다. 기본부문은 파일이 커서 1~2분 걸릴 수 있습니다.
3. 탭별 기능
   - **요약·검증**: 2023년 경제구조 핵심 지표, 한국은행 보도자료 수치와의 대조, 회계 항등식 검증, 계수표·역행렬 심화 검증
   - **시트 보기**: Excel의 12개 시트(총거래표, 수입·국산거래표, 총·수입·국산투입계수표, 생산·수입·부가가치유발계수표, 최종수요 항목별 유발액)를 선택해 값을 확인. 행·열 검색과 10열 단위 이동 지원
   - **산업 검색**: 산업명·코드로 검색(다른 분류의 이름과 일치해도 현재 분류의 산업으로 연결). 산업을 누르면 상·하위 분류, 수요·투입 구조, 유발계수, 주요 투입처·판매처를 표시
   - **지표·순위**: 14개 지표별 순위 막대그래프, 산업 유형 분류, 정렬·필터 가능한 전체 표, CSV 저장
   - **최종수요 유발효과**: 소비·투자·수출 항목별 생산·부가가치·수입 유발액과 해당 항목으로 가장 크게 유발되는 산업
   - **시뮬레이터**: 하나 이상의 산업에 최종수요 증감(억원·조원·백만원, 음수 가능)을 입력해 전 산업의 생산·부가가치·수입 유발액 계산
   - **사용 안내·단위**: 단위, 지표 정의, 한계, 자료 출처

## 분석 방법

산업 수를 n, 국산거래표 기반 투입계수 행렬을 Ad, 수입투입계수 행렬을 Am, 산업별 부가가치율을 v라 할 때:

| 지표 | 산식 | 설명 |
| --- | --- | --- |
| 투입계수 | a_ij = x_ij ÷ 총투입_j | 산업 j 생산 1단위당 산업 i 투입 |
| 생산유발계수 | B = (I − Ad)^-1 | 최종수요 1단위가 전 산업에 유발하는 생산 |
| 부가가치유발계수 | V = v̂B | 최종수요 1단위가 유발하는 부가가치 |
| 수입유발계수 | M = Am·B | 최종수요 1단위가 유발하는 수입 중간재 |
| 영향력계수 | B 열합 ÷ 열합 평균 | 후방연쇄효과 (평균 = 1) |
| 감응도계수 | B 행합 ÷ 행합 평균 | 전방연쇄효과 (평균 = 1) |
| 중간투입률 / 부가가치율 | 중간투입 ÷ 총투입 / 부가가치 ÷ 총투입 | |
| 수입의존도 / 국산화율 | 수입 중간재 ÷ 총투입 / 국산 중간재 ÷ 중간투입 | |
| 수출률 / 수입률 | 수출 ÷ 총산출 / 수입계 ÷ 총공급 | |
| 시뮬레이션 | Δ생산 = B·Δf, Δ부가가치 = V·Δf, Δ수입 = M·Δf | Δf: 국산 최종수요 증감 |

산업 유형은 영향력계수와 감응도계수가 각각 1 이상인지에 따라 **중추형 / 최종수요 의존형 / 중간재 공급형 / 독립형** 으로 나눕니다.

### 검증 (model.py)

- 총거래표 회계 항등식(중간수요·최종수요·총수요·총산출·수입·총투입·부가가치 구성)
- Excel 합계와 한국은행 보도자료 수치 대조(총산출 5,786.7조원, 수입 1,016.0조원, 부가가치 2,383.3조원 등)
- Excel 계수표와 Python 재계산 비교(투입계수, 레온티에프 역행렬, 부가가치·수입유발계수, 영향력계수)

대분류·중분류·소분류·기본부문 네 자료 모두 위 검증을 통과합니다.

## 단위

| 구분 | 단위 |
| --- | --- |
| 거래액, 총산출, 부가가치, 유발액 | **백만원** (2023년 당해년 가격, 생산자가격). 화면에서는 억원·조원으로도 표시하며 단위를 함께 적음. 1억원 = 100백만원, 1조원 = 1,000,000백만원 |
| 투입계수, 유발계수 | 무차원 |
| 부가가치율·중간투입률·수입의존도·국산화율·수출률·수입률 등 | % |
| 영향력계수, 감응도계수 | 지수 (전산업 평균 = 1.0) |

당해년 가격 자료이므로 연도 간 증감 해석에 주의해야 하며, 모든 수치는 반올림되어 상위 부문과 하위 부문의 합이 다를 수 있습니다.

## 한계

- 시뮬레이터는 수요 주도 투입산출 모형입니다. 공급 제약, 가격 변화, 대체 효과, 소득 증가에 따른 추가 소비는 반영하지 않습니다.
- 2023년 연장표는 2020년 실측표를 기준으로 간접 추계한 값입니다.
- 총산출이 0인 부문(소분류 1개, 기본부문 5개)은 비율·계수 지표를 “-”로 표시합니다.
- 브라우저의 Pyodide는 외부 서버와 통신하는 기능이 제한적이며, GitHub Pages는 정적 웹사이트만 지원합니다. 이 웹앱은 Excel을 읽고 계산하는 데 서버가 필요하지 않습니다.

## GitHub Pages 게시 방법

1. 저장소(Public)의 **Code** 탭 → **Add file → Upload files**
2. 이 폴더의 파일을 **압축을 푼 상태로** 최상위에 업로드(폴더 `data/` 포함) → **Commit changes**
3. **Settings → Pages**: Source `Deploy from a branch`, Branch `main`, Folder `/ (root)` → **Save**
4. **Actions** 탭에서 배포 완료를 확인한 뒤 게시 주소에서 확인
